Web app

Gym Membership System

A web system for running a gym. It keeps members, membership plans, payments and daily check-ins in one place.

Key features

Member recordsAdd, edit and search members.
Membership plansSet up plans and track who is active.
PaymentsRecord payments and see who has paid.
Check-insLog every gym visit.

Tech used

FlaskSQLHTML/CSS/JS

How it works

1

The admin adds a member and picks a plan.

2

The member pays and the system records the payment.

3

At the gym, the member's visit is logged as a check-in.

4

The admin reviews members, payments and visits any time.

Hours trackingTracks completed OJT hours and completion.
Activities and documentsStudents submit activities and files.
Correction requestsRequest fixes to a record.

Tech used

FlaskSQLJavaScript
