Programming language

Hello, World! inPython

Python is simple to read and great for beginners. Here is how to run your first program.

3 steps1 result
Steps
1

Install Python

Download it from python.org. In the installer, tick “Add Python to PATH”, then click Install. Check that it works:

Terminal
python --version
2

Create hello.py

Make a new file named hello.py (you can use VS Code or Notepad) and type:

hello.py
print("Hello, World!")
3

Run it

Open a terminal in the same folder (in VS Code press Ctrl + `) and run:

Terminal
python hello.py

If “python” is not recognized, try this instead:

Terminal
py hello.py

✓Expected result

Output
Hello, World!

Styling language

Hello, World! inCSS

CSS makes HTML look good: colors, fonts and layout. You write it in a separate file and link it to your page.

3 steps1 result
Steps
1

Create index.html

This page links to a CSS file called style.css:

index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Hello, World!</h1>
</body>
</html>
2

Create style.css

Put it in the same folder:

style.css
body {
  background: #111;
  display: grid;
  place-items: center;
  height: 100vh;
  margin: 0;
}

h1 {
  color: #ff6b6b;
  font-family: Arial, sans-serif;
  font-size: 64px;
}
3

Open index.html

Open it in your browser (or Live Server) and change the colors to see what happens.

✓Expected result

Output
A dark page with a big red “Hello, World!” in the center.
Database language

Hello, World! inSQL

SQL is used to talk to databases. The easiest way to start is MySQL Workbench or XAMPP with phpMyAdmin.

4 steps1 result
SQL
Steps
1

Install MySQL

Install MySQL (with MySQL Workbench) from mysql.com, or install XAMPP and start MySQL from its control panel.

2

Open a query window

In MySQL Workbench, open a connection and click a new SQL tab. Or in the terminal:

Terminal
mysql -u root -p
3

Run your first query

Type this and run it (Ctrl + Enter in Workbench):

SQL
SELECT 'Hello, World!' AS message;
4

Try it with a real table

Create a database, a table, add a row and read it back:

SQL
CREATE DATABASE hello_db;
USE hello_db;

CREATE TABLE greetings (
  id INT PRIMARY KEY AUTO_INCREMENT,
  message VARCHAR(50)
);

INSERT INTO greetings (message) VALUES ('Hello, World!');

SELECT * FROM greetings;

✓Expected result

Output
+---------------+
| message       |
+---------------+
| Hello, World! |
+---------------+

Compile and run

In the terminal, in the same folder:

Terminal
javac Hello.java
java Hello

Hello, World! inC++

C++ is compiled into an .exe file. You need a compiler such as g++ (MinGW-w64 / MSYS2) or Visual Studio.

3 steps1 result
Steps
1

Install a compiler

On Windows, install MSYS2 (msys2.org) and then g++, or use Visual Studio with the “Desktop development with C++” workload. Check:

Terminal
g++ --version
2

Create hello.cpp

hello.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
3

Compile and run

Compile to hello.exe, then run it:

Terminal (Windows)
g++ hello.cpp -o hello
.\hello.exe

On Mac or Linux, run it like this instead:

Terminal
./hello

✓Expected result

Output
Hello, World!

Hello, World! inFlask

Flask lets you build websites with Python. Your “Hello, World!” will show up in the browser.

4 steps1 result
Steps
1

Install Flask

Make sure Python is installed, then run:

Terminal

Create app.py

app.py

Run the server

Terminal

Open it in your browser

Browser

Version control

Hello, World! inGit

Git saves the history of your code, so you can go back to any version. Your “Hello, World!” is your first commit.

4 steps1 result
Steps
1

Install Git

Download it from git-scm.com and install. Check:

Terminal
git --version
2

Tell Git who you are (one time only)

Terminal
git config --global user.name "Your Name"
git config --global user.email "you@email.com"
3

Make your first commit

Terminal
mkdir hello-git
cd hello-git
git init
echo "Hello, World!" > hello.txt
git add hello.txt
git commit -m "My first commit"
4

See your history

Terminal
git log --oneline

✓Expected result

Output
a1b2c3d My first commit
Code hosting

Hello, World! inGitHub

GitHub keeps your Git projects online. It can also host your portfolio for free with GitHub Pages.

4 steps1 result
Steps
1

Create an account and a repository

Sign up at github.com, click New repository, and name it hello-world. Do not add a README yet.

2

Push your project

In your project folder (after your first commit), replace YOUR-USERNAME and run:

Terminal
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/hello-world.git
git push -u origin main
3

Check it online

Refresh your repository page. Your files are now on GitHub.

4

Bonus: host a website

Go to Settings → Pages, choose the main branch, and Save. Your index.html goes live at https://YOUR-USERNAME.github.io/hello-world/

✓Expected result

Output
Your hello.txt file appears in the repository on github.com.

2
